# 시각적 타임라인·회고 UI

## 데이터 소스

- **타임라인**: `JournalEntry` 목록 + `AiArtifact` 중 `reflection_card` / `timeline_summary`.
- **페이지네이션**: `cursor` 기반 (createdAt + id).

## UI 계약 (클라이언트)

- 타임라인 아이템: [JournalTimelineItem](../../src/types/journal.ts) 타입 참고.
- “시각적” 강화(1.1): 썸네일 URL, 테마 컬러는 `AiArtifact.payload`에만 의존하지 말고 **엔트리 메타**와 분리.

## 캐시

- 이미지/썸네일은 CDN/객체 스토리지 URL + `Cache-Control`.

## 구현 이력 (레포 동기화)

UI·데이터 계약 보완. (최신이 위.)

### 2026-04-01

- **타임라인 인터페이스(웹 프로토타입):** 모아보기 기본 화면을 타임라인으로 전환. 상단에 방향 토글(`가로`/`세로`)을 두고, 기본은 가로.
- **가로 타임라인 동작:** 기록 카드를 가로 스와이프로 탐색하면 하단 dot-라인 타임라인이 함께 슬라이딩되고, 현재 카드의 dot가 뷰포트 중앙에 오도록 동기화.
- **dot 표현 규칙:** 1개월 경계(`day=1`)는 더 큰 점/강한 컬러, 1주 경계(월요일)는 중간 강도, 일반 일자는 기본 dot로 구분.
- **전환 로딩:** 방향 전환 시 카드 로딩 스켈레톤을 거쳐 레이아웃 전환되도록 처리.
- **날짜축 정렬:** 하단 dot를 기록 개수 기준이 아닌 **1년 날짜 기준(365일)** 으로 재구성. 좌우 여백 없이 화면 끝까지 이어지는 선/점 구조로 연속된 과거·미래 날짜 흐름을 인지하도록 보정.
- **제스처 충돌 완화:** 가로 카드 영역에서 트랙패드 수평 제스처를 컨테이너 내부 스크롤로 소비하도록 처리해 OS/브라우저 외부 스와이프 충돌을 줄임.
- **하단 타임라인 시각 정리:** `과거/미래` 텍스트 제거, 하단 타임라인 래퍼의 배경색/상단 보더 제거.
- **카드 전용 플리킹:** 네이티브 가로 스크롤 대신 카드 인덱스 슬라이더(드래그 오프셋 기반)로 전환해 카드 영역 외 배경에서의 스와이프 반응을 제거.
- **스와이프 범위 제한:** 가로 카드 슬라이더의 포인터 이벤트를 카드 컴포넌트 래퍼에만 연결해 카드 바깥 영역에서의 스와이프 입력을 차단.
- **날짜 라벨 규칙:** 하단 타임라인에 주 단위(`월요일`) `MM/DD` 라벨 표기, 연도 경계는 해당 `1/1` 지점에 `YYYY` 라벨만 표기.
- **뷰포트 기준 카드 배치:** 현재 카드는 가로 중앙(불투명 100%), 이전/다음 카드는 좌우 끝에서 40px만 노출(불투명도 70%)되도록 트랙을 재구성.
- **간격 계산 기준 보정:** 카드 트랙 step을 내부 래퍼가 아닌 FeedPage 루트 뷰포트(가로 100%) 기준으로 재계산해, 카드 노출 폭/간격이 화면 폭 기준으로 일관되게 동작하도록 수정.
- **피크 노출 보정:** 카드가 실제로 클리핑되는 `main` 뷰포트 폭 기준으로 40px 피크 계산을 재적용해 이전/다음 카드 노출 폭 오차를 줄임.
- **카드 상단 날짜 제거:** 카드 위 `DateLabel`은 제거하고, 날짜는 카드 내부 콘텐츠(추후 구성)로 이동 가능한 상태로 정리.
- **카드 내부 메타 구성:** `FeedRecordCard`/`Card2LineVer`를 확장해 기록 날짜(`DateLabel`)를 카드 내부로 이동하고, 저장된 날씨 정보(`time + icon + weatherLine`)와 함께 표출되도록 연결.
- **하단 구조 재배치:** `BottomNavBar`를 제거하고, 하단 날짜 dot 타임라인을 `feed` 메인 뷰포트 하단 고정(`absolute bottom`)으로 이동해 타임라인 탐색 UI를 우선 배치.
- **하단 조작 영역 확장:** 하단 타임라인 컨테이너 높이를 `64px`로 고정(`h-16`)하고, 가로 제스처(`pan-x`)와 내부 오버스크롤 처리를 명시해 스와이프 조작 영역을 확보.
- **구조 가독성 개선:** 하단 dot/line/label 렌더링을 `FeedTimelineDots` 컴포넌트로 분리해 `feed/page.tsx`의 중첩을 줄이고 요소 의미를 명확화.
- **도트 사이즈 규칙 적용:** 기록 있는 날짜 dot는 `12px`, 기본 상태 dot는 `8px`로 분기하고, 크기는 `--spacing12`/`--spacing8` 토큰(4/8 배수)으로 지정.
