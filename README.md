# remind-app

순간을 기록하고, AI와 함께 되돌아보는 마이크로 저널링 앱

---

## 핵심 고객

생각나는 것을 바로바로 꾸준히 기록하고,  
나중에 다시 꺼내보고 싶은 사람들을 위한 앱입니다.

## 핵심 기능

| 기능 | 설명 |
|------|------|
| **마이크로 저널링** | 짧은 텍스트와 감정 태그로 순간을 빠르게 기록 |
| **날씨 스냅샷** | 저장 시점의 날씨·위치를 기록에 자동 첨부 |
| **타임라인 피드** | 쌓인 기록을 가로·세로 뷰로 한눈에 확인 |
| **AI 회고** | 패턴 분석과 리마인더로 기록을 의미 있게 연결 *(예정)* |
| **홈 화면 위젯** | 앱을 열지 않고도 홈 화면에서 바로 기록 *(예정)* |

## 핵심 가치

**자아성찰**
- 기록을 꾸준히 해온 나 자신을 보며 자기 신뢰가 생깁니다.
- 시간이 지난 기록에서 내가 무엇에 반응하고 무엇을 중요하게 여기는지 패턴이 보입니다.
- 예전 기록과 지금을 비교하며, 막연했던 성장이 기록으로 증명됩니다.

**안도감**
- 머릿속에 맴돌던 생각을 꺼내 놓은 가벼움을 느낍니다.
- 흘러가버릴 뻔한 순간들이 내 것으로 보존되어 있다는 안도를 얻습니다.
