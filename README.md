# remind-app

순간을 기록하고, AI와 함께 되돌아보는 마이크로 저널링 앱

---

## 핵심 고객

바쁜 일상 속에서 생각과 감정을 짧게 남기고 싶지만,  
긴 글쓰기가 부담스러운 사람들을 위한 앱입니다.

## 핵심 기능

| 기능 | 설명 |
|------|------|
| **마이크로 저널링** | 짧은 텍스트와 감정 태그로 순간을 빠르게 기록 |
| **날씨 스냅샷** | 저장 시점의 날씨·위치를 기록에 자동 첨부 |
| **타임라인 피드** | 쌓인 기록을 가로·세로 뷰로 한눈에 확인 |
| **AI 회고** | 패턴 분석과 리마인더로 기록을 의미 있게 연결 *(예정)* |
| **홈 화면 위젯** | 앱을 열지 않고도 홈 화면에서 바로 기록 *(예정)* |

## 핵심 가치

- **로컬 우선** — 네트워크 없이도 기록은 항상 내 기기에 먼저 저장됩니다.
- **원문 보존** — AI는 기록을 분석할 뿐, 원문을 수정하거나 대체하지 않습니다.
- **낮은 마찰** — 한 줄이면 충분합니다. 완성된 글이 아닌 순간의 단편으로도 가치 있습니다.
